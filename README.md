# Portfolio

## 概要
このアプリは、私（okc33）のポートフォリオサイトです。過去のプロジェクト、スキルセット、および連絡先情報をまとめています。シンプルで分かりやすいデザインを目指し、誰にでも情報を提供できるよう構築されています。

## 主な機能
- **プロジェクト紹介**: これまで手掛けたプロジェクトのリストと説明を掲載。
- **スキルセット**: 使用可能なプログラミング言語・フレームワーク・ツールセットを示すセクション。
- **連絡先情報**: SNSリンク、メールアドレスなど、簡単にコンタクトを取れる手段を公開。

## 使用技術
- フロントエンド: HTML, CSS, JavaScript
- バックエンド: 未使用 (静的ホスティング)
- デザインツール: Figma

## デプロイ
このポートフォリオサイトは GitHub Pages を利用してデプロイされています。最新の状態に保つよう心掛けています。
